
## Tela de Login ##

Meu primeiro projeto de desenvolvimento web, criado com o objetivo de praticar lógica de programação e aplicar meus conhecimentos em HTML, CSS e JavaScript.

## Tecnologias utilizadas ##
- HTML5
- CSS3
- JavaScript

## Objetivo do projeto ##
Desenvolver uma interface de login funcional, praticando conceitos de programação, manipulação do DOM, eventos e validação de dados.

## Sobre o desenvolvimento ##
Este foi meu primeiro projeto desenvolvido sem utilizar inteligência artificial para escrever o código.

Durante o desenvolvimento, enfrentei desafios, resolvi problemas e aprimorei minha lógica de programação.
